What this tool can and cannot do

It shows the IP address websites see when you connect, plus ISP, ASN and an approximate location from a public database. Location is approximate and can be wrong, especially on mobile and VPN connections.

Why isn't this a DNS leak test?

A real DNS leak test needs an authoritative DNS server that records which resolver asks for a unique random hostname. A static page cannot do that, so we do not claim it. If you need one, use a dedicated service.

What is a WebRTC leak?

WebRTC can reveal IP addresses to websites, including a local network address or a public address that differs from your VPN address. Modern browsers often hide local addresses behind random .local names, which counts as protected.

Your IP may be sent to ipify.org, ipwho.is and ipapi.co for comparison or lookup; zrina.app does not store it. Related: check if a website is reachable.
