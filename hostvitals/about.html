About & Methodology

Website checks with transparent results.

HostVitals is an independent website connectivity checker built by Zrina as part of the zrina.app utility ecosystem. It compares a browser fetch with its edge HTTP status probe and a DNS lookup; public gateways are fallbacks if the edge probe is unavailable. Inquiries & Feedback: tools@zrina.app

Why HostVitals Was Created

A website can behave differently depending on the network path, resolver, and security rules used by a request. A single check cannot tell whether a site is unavailable to everyone or only from a particular network.

HostVitals therefore compares two limited vantage points: a fetch initiated by your browser and an HTTP status check made by its Cloudflare Pages Function. Public gateways are used only if that check is unavailable. Its findings describe only the checks used and should not be read as a worldwide uptime verdict.

Our Diagnostic Checks

1. DNS-over-HTTPS (DoH)

Queries Cloudflare's public DNS-over-HTTPS endpoint for A, AAAA, CNAME, and HTTPS records. This is one public resolver, not a comparison of global DNS providers.

2. Browser Fetch

Times a fetch from your browser to the entered URL. The fetch uses no-cors, so the browser does not expose the HTTP status; the timing is not a TLS handshake measurement.

3. HTTP Status Inspection

Requests HTTP status directly through the HostVitals edge function. If that function is unavailable, public gateway services are used as a fallback; neither path represents every region or establishes the state of the origin server.

4. IP & Network Metadata

Looks up provider, ASN, and approximate location metadata for one resolved IP address. Anycast and CDN routing can mean this is not the origin server or the edge serving your browser.

5. Official Service Status (Supported Services)

When checking supported GitHub, Cloudflare, or OpenAI domains, HostVitals also retrieves that provider's published status summary and component notices. The official status page is a separate signal: it describes the provider's report, not your exact route or every user. HostVitals does not perform checks from a global network of locations.

Privacy-First Local History

Your recent checks and theme preference are stored in browser localStorage. Diagnostic requests also go to external DNS, gateway, and IP-metadata services; read the Tools Privacy Policy for the providers involved.
