    Frequently Asked Questions

    Why does a website show as UP on HostVitals, but DOWN for me?
    HostVitals compares a browser fetch with an HTTP status check from its edge function. If that function is unavailable, it may fall back to public gateway services. Differences between probes do not prove the issue is only on your device or that the site is up for everyone. Compare from another network and check your local DNS or firewall settings if appropriate.
    What do HTTP 500, 502, 503, and 504 status codes mean?
    HTTP 5xx status codes mean a server or gateway reports a service-side problem. They do not prove a total outage or identify which component failed:

    • HTTP 500 (Internal Server Error): The website's backend application encountered an unhandled exception or database error.
    • HTTP 502 (Bad Gateway): The edge reverse proxy (such as Cloudflare, Nginx, or AWS ALB) is online, but received an invalid response from the origin server behind it.
    • HTTP 503 (Service Unavailable): The responding server or gateway reports temporary unavailability; this can also be used for a security challenge.
    • HTTP 504 (Gateway Timeout): The edge network could not receive a timely response from the upstream origin server.
    What is a WAF false-positive (HTTP 403 Forbidden)?
    An HTTP 403 means a server or gateway returned a response, but does not by itself prove a WAF caused it. An HTTP 503 can mean temporary unavailability, maintenance, or a security challenge. HostVitals reports the response observed by its edge probe or a public gateway fallback; neither result alone identifies the cause or proves a global outage.
    How does HostVitals test website reachability and privacy?
    HostVitals compares a browser fetch with an HTTP status check from its edge function, falling back to public gateway services if needed, and queries Cloudflare DNS-over-HTTPS for DNS records. The browser fetch time is not a TLS handshake measurement, and its no-cors response does not expose the HTTP status. These checks do not represent a global network of probes, so results describe only the paths used. Recent checks are stored in your browser's localStorage.
