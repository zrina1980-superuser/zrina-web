Privacy Policy for zrina.app Tools

Applies only to the tools listed below · Last updated: November 2026

This policy covers HostVitals, Download Time Calculator, Subnet & CIDR Calculator, JSON Formatter, Unix Timestamp Converter, Cron Explainer, Network & IP Inspector, UUID Inspector, Network Planner, QR Code Generator, Password Generator, Base64 Encoder / Decoder, Regex Tester and Unit Converter. It does not cover the zrina.app portfolio homepage or project pages.

Information processed by each tool

  • HostVitals: When you run a check, your browser contacts the hostname through Cloudflare DNS-over-HTTPS, makes a browser fetch to the submitted target, and may send the URL to public status gateways (api.microlink.io and api.allorigins.win) as fallbacks. The Cloudflare-hosted edge probe receives the submitted URL and requests it to read an HTTP status. For supported GitHub, Cloudflare and OpenAI hostnames, the edge function also requests the matching provider's public status summary from githubstatus.com, cloudflarestatus.com or status.openai.com. That status request uses a fixed provider URL and does not forward the submitted target URL or your IP as a data field; the status provider receives routine request information from the Cloudflare edge. A resolved IP address may be sent to ipwho.is for network metadata. Popular service icons are local and do not request the checked domain or an external favicon provider. Recent checks and your theme preference are stored in your browser’s local storage.
  • Network & IP Inspector: Your browser requests public IPv4/IPv6 addresses from api.ipify.org and api6.ipify.org, and requests a secondary public-address result from ipapi.co for comparison. It then requests network details from ipwho.is; if that lookup is unavailable, it may try ipapi.co for the selected IP. Only when you choose “Run WebRTC check,” your browser contacts stun.l.google.com.
  • UUID Inspector: Identifiers you enter are decoded and generated locally in the browser. They are not sent to an application server unless you choose a link that places an ID in the page URL; ordinary hosting logs may then include that URL.
  • Network Planner: Address pools, network blocks, and host requests are analyzed locally. If you choose “Copy share link,” those entered values are included in the URL; when that URL is opened, it is part of the ordinary request URL that may be processed by hosting logs.
  • Download Time Calculator, Subnet & CIDR Calculator, JSON Formatter, Unix Timestamp Converter and Cron Explainer: Calculations and parsing run in your browser; the values you enter are not sent to an application server by these tools.
  • QR Code Generator and Scanner: Entered content, logo files, selected images and camera frames are processed locally in your browser and are not uploaded by the tool. The camera is used only after you start it and grant permission, and stops when the page is hidden. Exported files and copied images are created on your device.
  • Password Generator: Passwords and passphrases are generated in your browser using its cryptographic random source. Results are not sent to an application server or saved by the tool.
  • Base64 Encoder / Decoder: Text and selected files are processed locally in your browser. The tool does not upload the input or output.
  • Regex Tester: Patterns and test text are processed locally in a disposable browser worker with a time limit. They are not sent to an application server or saved by the tool.
  • Unit Converter: Values and conversions are processed locally in your browser. If you enable the optional history feature, the last 10 conversions are stored in this browser’s local storage; they are not sent to an application server.

Third-party services and hosting

Tool pages use system fonts and do not load Google Fonts. The services described above receive your IP address and ordinary connection/request information when your browser contacts them; services that process a submitted URL also receive that URL. Their own privacy terms and retention practices apply. The hosting provider may process technical request data in server logs; exact fields and retention depend on the provider’s configuration.

Advertising, consent and affiliate links

Advertising and affiliate links are not currently active on these tools. AdSense code and ad-slot examples, where present in source files, are comments and do not load or display ads. No advertising consent platform is currently integrated. If ads are enabled later, the policy, consent choices and relevant provider details will be updated before activation. The portfolio homepage and project pages remain ad-free and are not covered by this tools policy.

Your choices and contact

You can clear HostVitals’ locally saved check history using its “Clear all” control and clear other browser storage through your browser settings. You can avoid the optional WebRTC request by not running that check. For privacy questions, contact tools@zrina.app.
